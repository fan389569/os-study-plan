# 操作系统四个考点 · 图解与手算

单文件页面：`dist/index.html`（约 218KB，无外部资源、无网络依赖）。

## 打开

- 双击 `dist/index.html`，或双击 `打开页面.bat`。
- 本机服务已启动时，也可以直接访问 <http://127.0.0.1:8765/>。

## 操作

- 顶部 5 个页签：文件索引 / 地址变换 / 首次适应 / 快表 TLB / 复盘与自测。
- 模块 1–4：播放/暂停、上一步/下一步、0.5× / 1× / 2×、场景标签跳转与下拉跳转；空格、←、→ 是快捷键。
- 右上角切换浅色/深色；手机竖屏已适配。
- 模块 5：一页纸公式卡（打印/存 PDF 只输出这一页）+ 6 道自测，答案默认收起，点“看答案”逐条展开。

## 计算与校验

所有题目的中间步骤和答案都由 `src/solver.js` 的同一份数据计算，页面不手写答案。

```bash
node verify.cjs   # 逐项核对题目给出的核心参考值
node build.mjs    # 重新打包 dist/index.html
```

## 口径

- inode 已在内存：读盘次数 = 索引块层数 + 最后读数据块。
- 块号、页号、逻辑块号都从 0 起；区间写成左闭右开 `[起, 止)`。
- “最大文件”只算可寻址的数据块；“实际占用”才加索引块。
- TLB 未命中计入查 TLB 的时间：`t + 2m`，与本课程试卷口径一致。
- 一级/二级/三级间接分别指 1/2/3 层索引块；inode 有 10 个直接指针，一、二、三级各 1 个。
- 试卷里的 17.135GB、1AE0H 两个答案按题面数据判断为错，页面已标注并给出计算结果。
