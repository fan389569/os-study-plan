一、单选题

每题 2 分，共 30 分
1 单选

通道

通道又被称为 I/O 处理器，它用于实现（　）之间的信息传输。
答案与解析

答案：A

解析

通道是专门负责 I/O 的处理机，与 CPU 并行工作，直接在主存与外设之间成块传送数据。CPU 只需发一条 I/O 指令，通道干完活再中断通知。

「CPU 与外设」是中断驱动方式给人的印象（CPU 亲自搬每一个数据），而通道恰恰是为了把这段搬运动作从 CPU 手里拿走才出现的。

2 单选

页表始址

页式管理中，页表的始地址是存放在（　）。
答案与解析

答案：D

解析

页表本身存放在内存，但它的起始地址和长度放在进程 PCB 的页表始址寄存器、页表长度寄存器里，进程被调度时装入 CPU。

联想存储器（TLB）缓存的是「页号 → 块号」的页表项，不是页表始址，别混。

3 单选

文件重名

如果允许不同用户的文件可以具有相同的文件名，通常采用（　）来保证按名存取的安全。
答案与解析

答案：D

解析

同名文件冲突靠多级目录解决：每个用户有自己的目录，路径 = 用户名 + 文件名，不同用户下的同名文件自然可以共存。

索引表、指针解决的是查找速度和文件共享，都不解决「名字冲突」。

4 单选

死锁·打印机

若系统中有 7 台打印机，有多个进程均需要使用两台，规定每个进程一次仅允许申请一台，则至多允许（　）个进程参与竞争，而不会发生死锁。
答案与解析

答案：A

解析

设参与竞争的进程为 n 个，每个进程最终都要 2 台。最坏情况是每个进程先各拿 1 台、都在等第 2 台——此时已占用 n 台，若再无空闲就形成死锁。

7 台时：n = 6 只占 6 台，还剩 1 台，谁拿到谁就能完成并释放 2 台，死锁无法成立；n = 7 时 7 台全被占满，谁都拿不到第 2 台，死锁成立。故至多 6 个。

通用结论：资源 R 台、每进程最多需 m 台时，进程数 n 满足 n(m−1) < R 就不会死锁（这里 6×1 < 7）。

5 单选

管态

当 CPU 执行操作系统代码时，称处理机处于（　）。
答案与解析

答案：C

解析

处理机有两种状态：管态（核心态、系统态）执行 OS 内核代码，可执行特权指令；目态（用户态）执行用户程序。执行操作系统代码时当然处于管态。

6 单选

缓冲技术

CPU 输出数据的速度远远高于打印机的打印速度，为了解决这一矛盾，可采用（　）。
答案与解析

答案：B

解析

CPU 输出快、打印机慢，速度差几个数量级，用缓冲技术：CPU 把数据写进缓冲区就返回，打印机慢慢从缓冲区取，两者解耦。

并行技术提高并行度但不解决速度差；通道解决的是 CPU 参与度；虚存管的是地址空间。

7 单选

首次适应

将主存空闲区按地址顺序从小到大登记在空闲区表中，每次分配时总是顺序查找空闲区表，此种分配算法称为（　）分配算法。
答案与解析

答案：A

解析

判定只看两点：空闲区表按地址递增登记 + 每次从表头顺序查找第一个够用的 → 首次适应。

若按容量递增排序，找到的就是「能满足的最小空闲区」，那是最佳适应；按容量递减则是最大（最坏）适应。排序方式一换，算法就换。

8 单选

I/O 由谁完成

用户程序中的输入、输出操作实际上是由（　）完成。
答案与解析

答案：C

解析

用户程序里的 read / write 只是系统调用接口，真正的设备控制、数据传输由操作系统的设备管理模块完成，用户感知不到硬件细节。

9 单选

流式文件

以字符为基本单位按照一定顺序组成的文件叫做（　）。
答案与解析

答案：C

解析

按逻辑结构分：流式文件以字符（字节）为基本单位，无记录概念；记录式文件以记录为基本单位。题干关键词是「以字符为基本单位」。

10 单选

解除死锁

采用资源剥夺法可解除死锁，还可以采用（　）方法解除死锁。
答案与解析

答案：B

解析

解除死锁两条路：剥夺资源（从某些进程手里强行收回）和撤销进程（杀掉代价最小的进程，释放它持有的全部资源）。

「拒绝分配新资源」属于预防 / 避免，是事前的策略，不是事后的解除手段。

11 单选

缺页中断

进程在执行中发生了缺页中断，经操作系统处理后，应让其执行（　）指令。
答案与解析

答案：A

解析

缺页中断发生在指令执行过程中（取指或取操作数时发现页不在内存），这条指令并没有执行完；调入页面后必须重新执行被中断的这条指令。

对比记忆：I/O 完成中断是在指令执行完之后才到来的，所以返回来执行下一条指令。这个对比是高频考点。

12 单选

段最大长度

采用段式存储管理的系统中，若地址用 24 位表示，其中 8 位表示段号，则允许每段的最大长度是（　）。
答案与解析

答案：A

原卷选项印作 216、28、224、232，是上标丢失。

解析

24 位地址 = 段号 + 段内偏移。段号占 8 位，段内偏移占 24−8 = 16 位，所以每段最大 216 字节（64KB）。

顺带：段数最多 28 = 256 段。题干里的 216、28 是上标丢失。

13 单选

FAT

通过 FAT 表可以直接获得的信息是（　）。
答案与解析

答案：B

解析

FAT 每个表项记录「本块的下一个块号」，顺着表项就能把整个文件的簇链串起来，所以直接得到的是块之间的连接信息。

表项为 0 确实也表示空闲，但那是「顺带能看出」，FAT 的设计本意是链接；本题按教材口径选 B。

14 单选

进程特性

在下列特性中，哪一个不是进程的特性（　）。
答案与解析

答案：B

解析

进程的四个特征：动态性（有生命周期）、并发性、独立性、异步性。

「静态性」是程序的特征——程序是静态的指令集合，进程是它的一次动态执行。

15 单选

共享文件

允许多个用户同时使用一个共享文件时，下列（　）做法是不对的。
答案与解析

答案：B

解析

共享文件的读写规则只有三句：多读可并发，读写必须互斥，多写必须互斥。

所以「允许读者和写者同时使用」是错的，其余三项都符合规则。

1 判断

磁盘缓冲

在系统内存中设置磁盘缓冲区的主要目的是减少磁盘 I/O 次数。
答案与解析

答案：√

解析

磁盘缓冲区把多次小的读改写合并、把顺序访问提前读进来，目的正是减少真正的磁盘 I/O 次数。

2 判断

FCFS 效率

先来先服务（FCFS）算法是一种简单的调度算法，但其效率比较高。
答案与解析

答案：×

解析

FCFS 只是实现简单、公平，效率并不高：短作业要排在长作业后面干等，平均周转时间偏大。

3 判断

死锁影响

一旦出现死锁，所有进程都不能运行。
答案与解析

答案：×

解析

死锁只让参与死锁的那部分进程永久阻塞，其他无关进程照常运行。只有当死锁持续、资源被耗尽时才可能拖垮整个系统，题干说「所有进程都不能运行」太绝对。

4 判断

PV 同步初值

用 P、V 操作实现进程同步，信号量的初值必须为 1。
答案与解析

答案：×

解析

信号量初值取决于语义：互斥信号量初值为 1；同步信号量表示「可用资源数」或「前驱是否完成」，初值可以是 0、1 或任意正整数。

例如「生产者先生产、消费者后消费」的同步信号量初值就是 0。所以「必须为 1」是错的。

5 判断

设备独立性

使用户编制的程序与实际使用的物理设备无关是由设备独立性功能实现的。
答案与解析

答案：√

解析

设备独立性（设备无关性）：用户程序用逻辑设备名编程，由 OS 在运行时映射到具体物理设备，程序与硬件解耦，换设备不用改程序。

6 判断

设备分类

按信息交换单位分类可将设备分为块设备和字符设备。
答案与解析

答案：√

解析

按信息交换单位分两类：块设备（磁盘，成块存取、可寻址）和字符设备（键盘、打印机，按字符流、不可寻址）。这是 I/O 设备的经典分类。

7 判断

虚存编址空间

在虚存系统中，只要磁盘空间无限大，作业就能拥有任意大的编址空间。
答案与解析

答案：×

解析

编址空间由地址字长决定（如 32 位机器最多 4GB），与磁盘有多大无关。磁盘再大也只能让虚拟空间「够用」，不能突破地址位数。

8 判断

等 CPU 的状态

进程申请 CPU 得不到满足时，其状态变为等待态。
答案与解析

答案：×

解析

申请 CPU 得不到满足 → 进入就绪态（万事俱备只欠 CPU）。

等待（阻塞）态是等 I/O 完成、等信号量等事件，两者不要混。这也是「就绪队列」和「等待队列」的区别。

9 判断

磁盘延迟

启动磁盘执行一次输入输出操作时，延迟时间是硬件设计时就固定的。
答案与解析

答案：×

解析

旋转延迟取决于磁头现在停在哪、目标扇区什么时候转过来，每次都不一样，不可能由硬件固定。

硬件固定的是数据传输率，所以固定的是传输时间，不是延迟时间。

10 判断

虚拟存储

在虚拟存储方式下，程序员编制程序时不必考虑主存的容量，但系统的吞吐量在很大程度上依赖于主存储器的容量。
答案与解析

答案：√

解析

虚存让程序员不必考虑主存大小（局部性 + 按需调页），但物理内存不足时缺页率上升、频繁换页，系统吞吐量会明显下降。所以「吞吐量依赖主存容量」是对的。

1 简答

抖动

什么是抖动现象？在请求分页系统中，产生抖动的原因是什么？（6 分）
答案与解析

抖动现象：在请求分页存储管理中，如果分配给进程的存储块数量小于进程所需要的最小值，进程将频繁地产生缺页中断，导致系统效率低下，这种现象称为抖动。（3 分）

产生原因：置换算法不合理；系统内的进程数量太多或置换算法不合理也会导致内存抖动。例如，系统在置换旧页面时，可能会频繁地将刚置换出去的页面再次调入，导致系统开销加大。（3 分）

解析

两个得分点分开写：① 定义——分配给进程的物理块少于它所需的最小块数，刚被换出的页很快又要访问，频繁缺页，CPU 大量时间耗在换页上；② 原因——分给进程的物理块太少（多道程序度过高），以及置换算法不当（如 FIFO 把常用页换出去）。

四、综合题

共 40 分
1 综合

磁盘调度

（6 分）设磁盘的 I/O 请求队列中的柱面号为 376、205、134、56、193、396、29、40，磁头的起始位置为 100（磁头的运行方向向外），请按下列算法分别计算为完成上述各次访问总共的寻道距离，写出求解过程。

（1）最短寻道距离优先算法　（2）循环扫描算法

答案与解析

（1）SSTF

100 → 134 → 193 → 205 → 56 → 40 → 29 → 376 → 396

34 + 59 + 12 + 149 + 16 + 11 + 347 + 20 = 648

（2）C-SCAN（循环扫描）

100 → 56 → 40 → 29 → 396 → 376 → 205 → 193 → 134

44 + 16 + 11 + 367 + 20 + 171 + 12 + 59 = 700

解析

先画数轴、定方向，再一步步取「当前最近」。题目「运行方向向外」按本卷口径是向小柱面走。

（4 分）设某系统采用页式虚拟存储管理，页表存放在主存中。

（2）如果增加快表（TLB），查找 TLB 的时间为 5ns，并且 80% 的页表访问命中 TLB，内存的有效访问时间是多少？

答案与解析

（1）页表存放在主存中，存取一次数据需两次访问内存：50ns × 2 = 100ns（2 分）

（2）增加 TLB 后：50ns + 5ns × 80% +（50ns + 5ns）× 20% = 65ns（2 分）

等价写法：0.8 × (5+50) + 0.2 × (5+50+50) = 65ns。

解析

没有 TLB：查页表一次 + 取数据一次 = 2 次访存 = 100ns。

有 TLB 要分清命中与未命中：
命中 80%：查 TLB 5ns + 访存 50ns = 55ns
未命中 20%：5 + 50（查页表）+ 50（取数）= 105ns
EAT = 0.8×55 + 0.2×105 = 65ns。

最常见错误是写成 0.8×(5+50) + 0.2×(5+50)，漏掉未命中时多出来的那一次访存。

SJF 计算

（4 分）有四个作业同时到达系统，它们的估计运行时间如下：

答案与解析

SJF 调度顺序：B(2ms) → D(4ms) → A(6ms) → C(10ms)

完成时间：B 2ms，D 6ms，A 12ms，C 22ms

周转时间：B 2ms，D 6ms，A 12ms，C 22ms；平均周转时间 = (2+6+12+22)/4 = 10.5ms

带权周转：1，1.5，2，2.2；平均带权周转时间 = 6.7/4 = 1.675

解析

四个作业同时到达 → 没有到达时间差，SJF 就是按执行时间从短到长排：B(2) → D(4) → A(6) → C(10)，完成时刻 2、6、12、22。

周转时间 = 完成 − 到达 = 2、6、12、22，平均 (2+6+12+22)/4 = 10.5ms。

带权周转 = 周转 ÷ 运行 = 1、1.5、2、2.2，平均 6.7/4 = 1.675。
